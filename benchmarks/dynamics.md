# Dynamics accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

One body that can move and turn any way it likes, told what is pushing on it: one case just spinning
with nothing acting on it, and one doing everything at once. The numbers to match come from MuJoCo,
and each is worked out a second time in numpy before it is saved, so an axis pointing the wrong way
is caught before the file is written.

In the equations, `m` is the mass, `c` the point the body balances on, `I` how hard it is to spin
about that point, `R` which way it is facing, `ω` how fast it is turning, `f` and `τ` the push and
turn applied, and `g` gravity.
