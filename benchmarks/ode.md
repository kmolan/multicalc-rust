# ODE integrators accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

The ODE integrators are tested against scipy (`solve_ivp`). The first rows integrate `y' = f(t, y)`
with the adaptive `Rk45` solver; the attitude rows step an orientation forward with
`ExponentialMap` and a free body forward with `RigidBody::stepped`, both at the fixed step named in
the row. Every row is checked against scipy within the listed tolerance.
