# Control accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

Nine fixtures: the quadrotor-hover Riccati solve and its Lyapunov certificate, the cart-pole
Riccati solve, the geometric attitude law, and five model-based arm laws (one of them also gives the
tool-frame Jacobian row). The Riccati and Lyapunov rows use the SciPy solvers. The attitude row
evaluates the same formula again in numpy. The arm rows take the model terms from Pinocchio and
evaluate the law in numpy, so they pin the conventions and the composition, not the formulas.

Symbols:

- LQR: `A` the state-transition matrix, `B` the input matrix, `Q` and `R` the state and input cost
  weights, `P` the cost-to-go.
- Attitude: `R` the attitude, `R_d` the target attitude, `ω` the angular rate, `J` the inertia
  tensor, `e_R` the attitude error, `e_ω` the angular-rate error.
- Arm: `H` the joint-space inertia, `C` the Coriolis and centrifugal term, `G` gravity, `J` the
  tool Jacobian, `X` the tool pose, `X_d` the target pose, and `q_d`, `q̇_d`, `q̈_d` the desired
  motion.
