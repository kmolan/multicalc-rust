# Control accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

Four checks: a flying machine's position loop, proof it settles, a cart balancing a pole, and the
attitude law. The first three use SciPy's own solvers; the last re-runs the same formula in numpy.

In the equations, `A` is how the state moves in one step, `B` how the input pushes it, `Q` and `R`
what state error and input effort cost, and `P` the resulting cost-to-go. On the attitude side `R`
is the current rotation, `R_d` the target, `ω` the turn rate, `J` the body's resistance to spinning,
`e_R` how far off the pointing is, and `e_ω` how far off the turn rate is.
