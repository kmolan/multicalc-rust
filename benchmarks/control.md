# Control accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

Nine checks: a flying machine's position loop, proof it settles, a cart balancing a pole, the
attitude law, and four model-based laws for a jointed arm. The first three use SciPy's own solvers;
the attitude row re-runs the same formula in numpy. The arm rows take Pinocchio for the model terms
and re-evaluate the law in numpy on top, so what they pin is the conventions and the composition,
not the formulas.

In the equations, `A` is how the state moves in one step, `B` how the input pushes it, `Q` and `R`
what state error and input effort cost, and `P` the resulting cost-to-go. On the attitude side `R`
is the current rotation, `R_d` the target, `ω` the turn rate, `J` the body's resistance to spinning,
`e_R` how far off the pointing is, and `e_ω` how far off the turn rate is. On the arm side `H` is
the joint-space inertia, `C` the Coriolis and centrifugal term, `G` gravity, `J` the tool Jacobian,
`X` the tool pose and `X_d` the one asked for, with `q_d`, `q̇_d` and `q̈_d` the desired motion.
