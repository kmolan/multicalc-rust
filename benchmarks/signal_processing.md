# Signal-processing accuracy

_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

The filters are tested against [SciPy](https://scipy.org)'s `scipy.signal`. Each row checks one thing
about the same designed filter: the weights it was built with, its strength and timing at eleven
frequencies from 1 Hz to 450 Hz, or the output of a fixed 64-sample sequence. Every filter is designed
for a 1 kHz sampling rate, and the input is a 5 Hz oscillation with a weaker 180 Hz one on top.

The design formulas are the same filter reached by different arithmetic, so these are tolerance
comparisons rather than bit-for-bit ones, and the filtered output compounds error over 64 samples.
`sharpness` is how abruptly a filter acts: about 0.707 gives the flattest low-pass, higher values a
narrower notch. Where a filter cancels a frequency completely, its timing there is not a defined
quantity, so those rows compare strength but not timing.
