_Table below generated by `cargo run -p multicalc-qa --bin gen_accuracy_tables`; do not edit it by hand._

Forward kinematics and geometric Jacobians against
[MuJoCo](https://github.com/google-deepmind/mujoco)'s `mj_kinematics` and `mj_jac`; inverse
kinematics against [mink](https://github.com/kevinzakka/mink)'s differential IK, on the same models.
Both IK solvers are local, so the IK cases pin the pose reached, and the joint configuration only
where it is locally unique.
